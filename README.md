# HR Analytics Project Using SQL

## Project Overview

This project focuses on analyzing Human Resources (HR) employee data using MySQL. The goal is to explore employee information, prepare data for analysis, and generate insights that can support HR decision-making.

## Objectives

* Explore employee data using SQL queries.
* Identify and handle data quality issues where applicable.
* Analyze employee demographics and workforce characteristics.
* Summarize HR data using aggregate functions and grouping.
* Practice SQL querying for real-world data analytics scenarios.

## Tools Used

* **Database:** MySQL
* **SQL Environment:** MySQL Workbench
* **Version Control:** GitHub
* **Dataset:**Excel/CSV

## Project Workflow

1. Imported employee data into MySQL.
2. Inspected the dataset and its columns.
3. Performed data quality checks and cleaning where applicable.
4. Wrote SQL queries to analyze HR data.
5. Reviewed query outputs to identify useful workforce insights.
